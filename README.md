# 🐾 PetRescue – Pet Adoption and Rescue Management System

## 📌 Project Overview

PetRescue is a web-based Pet Adoption and Rescue Management System developed as a Full Stack Development (FSD) project.

The main purpose of this project is to provide a simple platform where users can find pets, adopt pets, submit rescue requests, track rescue activities, report lost and found pets, and manage their applications.

The system provides different features for users and administrators to make pet adoption and rescue activities easier and more organized.

---

## 🎯 Objectives

- To provide an online platform for pet adoption.
- To help users find pets available for adoption.
- To allow users to submit adoption applications.
- To provide a rescue request system for pets in emergency situations.
- To allow users to track their rescue requests.
- To provide lost and found pet management.
- To provide an admin dashboard for managing the system.
- To provide a map-based interface for locating pets and rescue activities.
- To maintain pet and application information in an organized way.
